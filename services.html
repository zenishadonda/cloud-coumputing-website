CLOUD SERVICE MODELS

Types of Cloud Services

Cloud services offer different levels of control and management.

IaaS

Infrastructure as a Service

Provides virtual servers, storage, and networking. Example: Amazon EC2.

PaaS

Platform as a Service

Provides a platform for building and deploying applications. Example: Google App Engine.

SaaS

Software as a Service

Provides software over the internet. Examples: Gmail and Microsoft 365.
